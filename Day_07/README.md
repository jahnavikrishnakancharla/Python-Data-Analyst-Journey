# Day 7 - Loop Control Statements

## Topics Learned

- break
- continue
- pass

## break

`break` completely stops the loop.

## continue

`continue` skips the current iteration and moves to the next iteration.

## pass

`pass` does nothing at that point and allows the program to continue normally.

It is commonly used as a placeholder when code will be written later.
