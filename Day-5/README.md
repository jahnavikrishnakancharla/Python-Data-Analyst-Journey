# Day 05 - Python For Loops

## 🎯 Objective

Learn and practice Python `for` loops and use them to solve repetitive tasks and basic data-processing problems.

## 📚 Concepts Covered

- for loop
- range()
- Forward iteration
- Reverse iteration
- Even and odd numbers
- Multiplication tables
- Accumulator pattern
- Sum calculations
- Squares and cubes
- Conditional logic with loops
- Pattern printing

## 💻 Practice Programs

1. Print numbers from 1 to 10
2. Print numbers in reverse
3. Print even numbers
4. Print odd numbers
5. Print a name multiple times
6. Generate a multiplication table
7. Calculate sum of numbers from 1 to 10
8. Calculate sum of even numbers
9. Calculate squares
10. Calculate cubes

## 🧩 Challenges Completed

- Numbers divisible by 5
- Numbers divisible by both 3 and 5
- Factorial using a for loop
- Right-aligned star pattern
