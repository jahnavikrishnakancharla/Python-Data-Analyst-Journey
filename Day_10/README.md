## Python Terminology

### Collection
A collection is a group of multiple values stored together.

### Ordered
Ordered means elements have a fixed position or index.

### Immutable
Immutable means the data cannot be changed after creation.

### Indexing
Indexing means accessing an element using its position.

### Slicing
Slicing means extracting a portion of a sequence.

### Tuple Packing
Combining multiple values into one tuple.

### Tuple Unpacking
Assigning tuple elements to separate variables.

### Membership Operator
`in` and `not in` are membership operators used to check whether a value exists in a collection.

### Nested Tuple
A tuple containing other tuples.
